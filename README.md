# FairAI Audit

FairAI Audit is an AI-powered fairness auditing platform designed to detect bias in datasets and machine learning models. The system allows users to upload datasets, select sensitive attributes, train predictive models, and analyze fairness metrics through an interactive dashboard.

## Features
- Dataset upload and preprocessing
- Sensitive attribute selection
- Machine learning model training
- Fairness metric calculation
- Bias detection visualization
- Interactive dashboard
- Docker-based deployment

## Tech Stack
- Frontend: TypeScript, HTML, CSS
- Backend: Python
- Machine Learning: Scikit-learn
- Deployment: Docker
- Version Control: GitHub
